# Security Log Analyzer

Учебный проект на Python для анализа логов и выявления потенциально подозрительной активности.

Программа обрабатывает записи логов, анализирует события авторизации и подсчитывает количество неудачных попыток входа с каждого IP-адреса. Если количество неудачных попыток с одного IP достигает заданного порога, адрес добавляется в список подозрительных.

## Возможности

- Чтение логов из текстового файла.
- Разбор записей с помощью регулярных выражений.
- Подсчёт успешных и неудачных попыток авторизации.
- Подсчёт неудачных попыток входа по IP-адресам.
- Выявление подозрительных IP (3 и более неудачных попыток по умолчанию).
- Формирование отчётов в форматах JSON и CSV.
- Автоматическое создание директорий для сохранения отчётов.
- Обработка ошибок при отсутствии файла с логами.

## Используемые технологии

- Python
- ООП
- `re` — регулярные выражения
- `collections.Counter` — подсчёт событий
- `json` и `csv` — формирование отчётов
- `pathlib` — работа с файловыми путями
- `pytest` — подготовленные автоматические тесты

## Результат работы

После выполнения анализа программа выводит краткую информацию о результатах и сохраняет два отчёта в директории `reports/`:

- `report.json` — общая статистика событий и список подозрительных IP.
- `suspicious_ips.csv` — IP-адреса и количество неудачных попыток авторизации.

Порог подозрительной активности по умолчанию составляет 3 неудачные попытки с одного IP.
